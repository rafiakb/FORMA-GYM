Hosting Vercel + login akun

Supaya progres workout tersimpan dan bisa dibuka di HP maupun laptop, website membutuhkan akun Supabase untuk database dan login. Vercel hanya menghosting bagian website. XAMPP/MySQL tidak digunakan untuk versi ini.

  1. Buat proyek Supabase di supabase.com/dashboard. Catat nama proyek dan kata sandi database (tidak perlu dimasukkan ke website).
  2. Buka SQL Editor > New query. Salin isi file database/supabase.sql lalu tekan Run. Tabel forma_user_data beserta aturan keamanan RLS akan dibuat.
  3. Di Supabase: Project Settings > API Keys (atau Connect / API Keys menurut dashboard). Salin Project URL dan publishable key (atau anon public key lama). JANGAN SALIN service_role/secret key.
  4. Buka file assets/config.js menggunakan VS Code atau Notepad. Ganti kedua placeholder seperti contoh berikut:
window.FORMA_CONFIG = {
  supabaseUrl: "https://PROJECT-ID.supabase.co",
  supabaseAnonKey: "sb_publishable_...."
};
  1. Pastikan file index.html tetap di akar ZIP, bukan di dalam folder tambahan. Kompres ulang seluruh isi folder FORMA_Gym_Vercel sebagai ZIP.
  2. Upload ZIP itu di vercel.com/drop, isi nama proyek misalnya forma-gym-online, lalu klik Deploy.
  3. Salin URL HTTPS hasil deployment. Di Supabase buka Authentication > URL Configuration. Set Site URL ke URL HTTPS Vercel kamu (contoh: https://forma-gym-online.vercel.app) dan tambahkan URL itu di Redirect URLs (misalnya https://forma-gym-online.vercel.app/**). Ini penting untuk verifikasi email. Tambahkan juga URL https://forma-gym-online.vercel.app/reset-password.html agar reset password bisa dibuka.
  4. Di Supabase: Authentication > Providers > Email. Pastikan provider email aktif. Sebaiknya biarkan email confirmation aktif; setelah daftar, periksa email dan klik tautan verifikasi. Untuk produksi, pertimbangkan SMTP sendiri karena email bawaan Supabase dibatasi.
  5. Kunjungi URL Vercel kamu, buat akun, login, mulai latihan dan pilih Selesaikan & simpan. Keluar lalu login di HP lain menggunakan akun yang sama untuk menguji progres.

Perhatian: versi ini memakai Supabase PostgreSQL, bukan file MySQL lama. Katalog 26 gerakan dan 7 program adalah data statis yang disertakan dalam ZIP; data pengguna disimpan dengan RLS. Draft sesi aktif disimpan sementara di browser perangkat, lalu menjadi permanen saat sesi diselesaikan.
